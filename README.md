# Video Anomaly Detection (VAD) using Visual Language Model (VLM)
Данный проект предназначен для обнаружения нештатных ситуаций в видеопотоке с использованием визуально-языковой нейронной сети CLIP. Система анализирует изображения и текстовые описания, классифицируя сцены и выявляя потенциально опасные события, такие как аварии, пожары или драки. В качестве данных для обучения используется UCF-Crime – набор видео с классификацией различных инцидентов.
